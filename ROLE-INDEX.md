# Role Skill Index

Each linked file below contains the complete, standalone role instructions. Load only the relevant role skills for the task.

- [Product Analyst](skills/roles/product-analyst/SKILL.md) — Turn user and business needs into clear, testable scope; activate for new features, ambiguous requests, workflow changes, or acceptance disputes.
- [Solution Architect](skills/roles/solution-architect/SKILL.md) — Own cross-system design, architecture boundaries, technical decisions, and integration trade-offs; activate for multi-service, cross-platform, major refactor, or high-risk changes.
- [API Manager](skills/roles/api-manager/SKILL.md) — Own API standards, interface contracts, versioning, compatibility, and lifecycle; activate when APIs are created, changed, consumed, or integrated.
- [Backend Developer](skills/roles/backend-developer/SKILL.md) — Implement server-side domain logic, services, jobs, and business workflows; activate for server behavior, persistence orchestration, or backend defects.
- [Frontend Developer](skills/roles/frontend-developer/SKILL.md) — Implement client applications, UI state, accessibility-conscious interactions, and API consumption; activate for browser/mobile/client interface work.
- [UX/UI Designer](skills/roles/ux-ui-designer/SKILL.md) — Shape user journeys, interaction patterns, visual hierarchy, and design-system guidance; activate for new or materially changed user experiences.
- [Database Manager](skills/roles/database-manager/SKILL.md) — Own data modeling, schema evolution, migrations, integrity, and query design; activate for persistence, data correctness, or database performance changes.
- [Integration Engineer](skills/roles/integration-engineer/SKILL.md) — Own end-to-end system-to-system connectivity, adapters, event flows, and reconciliation; activate for SaaS, partner, legacy, webhook, queue, or multi-system workflows.
- [Data Engineer](skills/roles/data-engineer/SKILL.md) — Build reliable ingestion, transformation, movement, and analytical data workflows; activate for ETL/ELT, event pipelines, imports/exports, or data products.
- [QA Manager](skills/roles/qa-manager/SKILL.md) — Own risk-based quality strategy, test coverage, evidence, defect triage, and release quality recommendation; activate for all meaningful changes and releases.
- [Penetration Tester / AppSec](skills/roles/penetration-tester/SKILL.md) — Identify and validate application, API, infrastructure, and integration security risks; activate for new trust boundaries, auth/data changes, dependencies, and security-sensitive releases.
- [DevOps / Site Reliability Engineer](skills/roles/devops-sre/SKILL.md) — Own build, deployment, runtime reliability, observability, infrastructure automation, and recovery; activate for deployment, platform, availability, or operational changes.
- [Performance Engineer](skills/roles/performance-engineer/SKILL.md) — Measure and improve latency, throughput, resource use, and scalability; activate when performance is a requirement, regression, or evidenced bottleneck.
- [Accessibility Specialist](skills/roles/accessibility-specialist/SKILL.md) — Evaluate inclusive access across interfaces and workflows; activate for user-facing UI changes, forms, navigation, media, and interaction patterns.
- [Technical Writer / Knowledge Engineer](skills/roles/technical-writer-knowledge-engineer/SKILL.md) — Own documentation quality, Obsidian knowledge structure, Graphify relationships, and centralized HTML report; activate on every meaningful change.
- [Release Manager](skills/roles/release-manager/SKILL.md) — Coordinate release readiness, change scope, approvals, rollout, rollback, and post-release verification; activate for production or shared-environment releases.
