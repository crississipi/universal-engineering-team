# Role Skill Index

Load only the roles needed for the current task. The linked `SKILL.md` files contain the complete role-specific instructions.

Use `SKILLS-RESOLVER.md` for task-to-role suggestions. It is a routing aid, not a substitute for reading the selected skills or checking actual project context.

- [Product Analyst](skills/product-analyst/SKILL.md) — Define user needs, requirements, priorities, and acceptance criteria.
- [Solution Architect](skills/solution-architect/SKILL.md) — Design system architecture, boundaries, cross-system decisions, and trade-offs.
- [API Manager](skills/api-manager/SKILL.md) — Define API contracts, standards, compatibility, versioning, and lifecycle.
- [Backend Developer](skills/backend-developer/SKILL.md) — Build server logic, domain services, jobs, and backend tests.
- [Frontend Developer](skills/frontend-developer/SKILL.md) — Build web/mobile interfaces, client state, and API integrations.
- [UX/UI Designer](skills/ux-ui-designer/SKILL.md) — Design user journeys, interaction patterns, visual hierarchy, and design systems.
- [Database Manager](skills/database-manager/SKILL.md) — Design data models, migrations, integrity constraints, and queries.
- [Integration Engineer](skills/integration-engineer/SKILL.md) — Connect external systems, webhooks, events, adapters, and reconciliation.
- [Data Engineer](skills/data-engineer/SKILL.md) — Design data pipelines, transformations, lineage, and quality controls.
- [QA Manager](skills/qa-manager/SKILL.md) — Plan risk-based testing, verify changes, triage defects, and report evidence.
- [Penetration Tester / AppSec](skills/penetration-tester/SKILL.md) — Assess application, API, infrastructure, and integration security risks.
- [DevOps / Site Reliability Engineer](skills/devops-sre/SKILL.md) — Manage CI/CD, infrastructure, observability, reliability, and recovery.
- [Performance Engineer](skills/performance-engineer/SKILL.md) — Measure and improve latency, throughput, resource use, and scalability.
- [Accessibility Specialist](skills/accessibility-specialist/SKILL.md) — Audit accessibility barriers, inclusive interactions, and assistive-technology support.
- [Technical Writer / Knowledge Engineer](skills/technical-writer-knowledge-engineer/SKILL.md) — Maintain technical docs, Obsidian, Graphify, diagrams, and system reports.
- [Release Manager](skills/release-manager/SKILL.md) — Coordinate release readiness, approvals, rollout, rollback, and verification.
- [Delivery Lead](skills/delivery-lead/SKILL.md) — Coordinate multi-role delivery, ownership, handoffs, blockers, and completion across engineering tasks.
