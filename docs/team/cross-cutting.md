# Cross-cutting engineering requirements

These requirements apply across specialist roles. Their IDs are stable references
for evaluation criteria, documentation, and future requirement relocation.

## REQ-CROSSCUT-VERIFY-001 — Evidence-based verification

<!-- REQ-CROSSCUT-VERIFY-001 -->

Requirement: Every meaningful change must have relevant verification evidence. Report the exact commands or checks run, their actual results, and any checks that were not run. Never describe an unexecuted check as passed.

## REQ-CROSSCUT-DOCS-001 — Documentation consistency

<!-- REQ-CROSSCUT-DOCS-001 -->

Requirement: Every meaningful change must account for applicable technical documentation, diagrams, Obsidian notes, Graphify relationships, and the central HTML report. Update only affected content, preserve canonical sources, and identify items that are not applicable.
